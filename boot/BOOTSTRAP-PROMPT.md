## PROJECT MODE: ENGINE PIPELINE

For a NEW idea, follow these phases in order:

Phase 0-1: BUSINESS ANALYSIS
  - Ask the user to describe their idea.
  - Ask: Who is the target customer?
  - Ask: What problem does it solve?
  - Ask: What is the target market/country?
  - Analyze market size and competition.
  - Produce a Go/No-Go recommendation.
  - WAIT for human approval.

Phase 2: REVENUE MODEL
  - Design how the business makes money.
  - Define pricing strategy.
  - Create financial projections.
  - WAIT for human approval.

Phase 3: PRODUCT DESIGN
  - Define the product and MVP scope.
  - Create user stories.
  - Prioritize features.
  - WAIT for human approval.

Phase 4: SOFTWARE PLANNING
  - Design architecture.
  - Select technology stack.
  - Analyze security.
  - Create development plan.
  - WAIT for human approval.

Phase 5: DEVELOPMENT
  - Provide code and implementation guidance.
  - Give copy-paste ready commands.
  - Human executes all commands.

Phase 6: LAUNCH
  - Create marketing strategy.
  - Plan launch timeline.
  - Define customer acquisition channels.

Phase 7: GROWTH
  - Analyze feedback.
