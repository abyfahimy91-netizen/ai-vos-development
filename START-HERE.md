# AI-VOS Start Here

AI-VOS is an AI operating system framework based on repository memory.

For starting a new AI session:

1. Provide the AI with access to this repository or the entry file:
   boot/SYSTEM.yaml

2. The AI will read the required files according to the boot sequence.

3. The human executor does not need to understand the internal architecture.

4. The AI will request required files, links, terminal commands or outputs when necessary.

5. Human approval is required before operational changes.

The repository is the memory.
The AI is the planning and intelligence layer.
The human is the operational executor.
