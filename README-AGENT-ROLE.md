## چه چیزی اینجا می‌ماند

| چیز | چرا |
|---|---|
| اسکیل و روشِ کار | ابزار، نه سندِ کسب‌وکار |
| دروازهٔ قوانین (`GATE.sh`) | ماشینِ اجرای قانون — روی هر دو ریپو قابل استفاده |
| قالبِ `DESIGN-NOTE` | ابزارِ گفت‌وگو با کاربر |

 نسخهٔ اصلی و به‌روزِ این ابزارها در `carname/06-decisions/` است.

## استفاده از دروازهٔ قوانین

```bash
sh 06-decisions/GATE.sh
```

خروجی نامعتبر یعنی کار متوقف است. قلاب `pre-commit` آن را خودکار اجرا می‌کند.

| دروازه | چه می‌سنجد |
|---|---|
| **G1** پیش از طراحی | چهار پرسش آشنایی |
| **G2** پیش از کد و داده | منبعِ عدد · ممیزی = خواندن نمونه · سنجش باور |
| **G3** پیش از انتشار | ذکر پوشش · حکم ایمنی · محرمانگی |
