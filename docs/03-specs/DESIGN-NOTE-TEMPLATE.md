## ۱) چهار پرسش اجباری

### پرسش ۱ — کاربر این را با چه کلمه یا جملهٔ خودش می‌گوید؟

> نقل مستقیم از متن کاربر بنویس — نه واژهٔ ما، نه برچسب فنی.

- جملهٔ کاربر: «…»
- شاهد: کجا آمده؟ (فایل / بند / تاریخ)
- واژهٔ ما چیست و چرا فرق دارد؟

اگر واژهٔ ما را انتخاب کردیم ولی شاهد متنی نداریم، **حدس زده‌ایم** — برگرد و بپرس.

### پرسش ۲ — این کار همان کاری است که الان می‌کند، یا جای دیگری می‌بردش؟

> آزمون یک‌خطی: آیا این صفحه کاری را می‌کند که کاربر تا حالا کرده، یا دارد یادش می‌دهد کار تازه‌ای بکند؟

- پاسخ: همان کار آشنا / جای دیگری
- اگر «جای دیگری»: چه چیزی جای آشنا را می‌گیرد؟ اگر هیچ، **حذف**
- شاهد بازار: کدام اپ کار مشابه کرد و ماند / کدام مُرد و چرا

اگر پاسخ «جای دیگری» است، این دقیقاً مسیر «تعمیرگاه‌یاب» است — شاهد: کومک، ۲٫۵ از ۲۵ رأی.

### پرسش ۳ — بدون لاگین هم ارزش می‌دهد؟

- پاسخ: بله / خیر
- اگر بله: دقیقاً چه چیزی می‌گیرد؟
- اگر خیر: `L-12` نقض است — بازنویسی یا ثبت دلیل (`P2`)

پروژه هیچ لاگینی ندارد، پس پرسش عملی است: آیا کاربر تا وقتی ارزش نگرفته می‌ماند؟

### پرسش ۴ — اگر انجام ندهد، باز چه چیزی می‌گیرد؟

> این پرسش، «صفر» را می‌گیرد و طبق معادلهٔ آشنایی، صفر یعنی همه‌چیز صفر.

- پاسخ: چیزی / هیچ‌چیز
- اگر هیچ‌چیز: تلهٔ فعال‌سازی — کاربر «تا مشکلی پیش نیاید به فکر ماشین نمی‌افتد»
- راه فرار: «بعداً» با زمان مشخص (`L-11`) / خروجی قابل بردن

## ۲) جدول اهرم‌های آشنایی

> برای هر عنصر صفحه بنویس کدام اهرم آشنایی را می‌زند.
> عنصری که هیچ اهرمی ندارد، یا حذف شود یا آشنا شود.

| عنصر صفحه | اهرم آشنایی | شاهد |
|---|---|---|
| | اثر آشنایی (واژه) | «وقت تعویض روغنت رسیده» |
| | پیش‌فرض (کار همیشگی) | |
| | ترس از زیان (ضرر نه فایده) | |
| | کاهش فزونی گزینه | |
| | اثبات اجتماعی (کاهش ابهام) | |
| | کاهش ریسک (اثبات امنیت) | | **پنج ممنوعیت G1:** «برو به پلتفرم ما» · صفحهٔ شلوغ · سؤال اضافه · واژهٔ رسمی · خروجی محبوس.
