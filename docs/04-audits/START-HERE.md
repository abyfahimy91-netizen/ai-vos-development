## ۸) ⚠️ دام‌های محیطیِ این سرور

| # | دام |
|---|---|
| ۱ | ⭐ `su postgres -c 'psql …'` برای کارهای superuser (peer auth روی `psql -U postgres` خطا می‌دهد) |
| ۲ | ⭐ جدول‌هایی که superuser ساخته برای `ALTER` به `carnameh` باید `OWNER TO carnameh` شوند |
| ۳ | ⭐ connection گاهی وسط کار قطع می‌شود ⇐ ⭐ **قبل از نتیجه‌گیری، وجودِ خطا را چک کن** (`L-45`) |
| ۴ | ⭐ `assert` روی متنِ فارسی: `ی` عربی/فارسی را نرمال‌سازی کن |
| ۵ | ⭐ `runl`/heredoc با کوتیشنِ تو‌در‌تو از راه ssh می‌شکند ⇐ `cat > file <<'EOF'` یا `cat local \| ssh host 'cat > f'` |
| ۶ | ⭐ ارقامِ فارسی در SQL: `::int` خطا می‌دهد ⇒ `translate(…,'۰۱۲۳۴۵۶۷۸۹','0123456789')` |
| ۷ | ⭐⭐ **دیسکِ این سرور کُند است**: `COPY` ۲٬۰۶۹ ردیف = **۱۹ ثانیه** · checkpoint = ۲۴–۳۴ ثانیه ⇐ بعد از بارِ سنگین، ۵۰۰ ممکن است از **کندی** باشد نه از کد |
| ۸ | ⭐ `COPY … WITH CSV HEADER` سرستون را **می‌بلعد** ⇒ اگر فایل فقط یک ردیف دارد، `COPY 0` می‌گیری |
| ۹ | ⭐ `psql -c` با چند دستور و کوتیشنِ تودرتو می‌شکند ⇐ فایلِ SQL را با `cat \| ssh … 'psql -f -'` بفرست |
| ۱۰ | ⭐⛔ **`cp a b \| ssh 'cat > x; cat > y'` فایلِ محلیِ `b` را بازنویسی می‌کند!** ⇐ `cp` یعنی کپی‌کردن، نه چسباندن. برای دو فایل، دو دستورِ جدا بفرست |
| ۱۱ | ⭐⛔ **دستورهای `psql -c` با `\| ssh` فاصله‌ها و کوتیشن را می‌بلعند** ⇐ کوئری را در فایل بنویس و بفرست |

## ۹) دستورهای پرکاربرد

```bash
# همگام‌سازیِ سه‌جا (الگوی امن)
cd /var/minis/shared/carnameh
cat DEVELOPMENT-SPEC.md > "/var/minis/mounts/Minis backup/carnameh/DEVELOPMENT-SPEC.md"
cat DEVELOPMENT-SPEC.md | ssh -o ConnectTimeout=25 carnameh 'cat > /opt/carnameh/docs/DEVELOPMENT-SPEC.md'

# سلامتِ سایت
ssh carnameh 'for u in / /find/ /diagnose/ /diagnose/mid/ /explore/ /trims/ /data-gaps/; do printf "%s:%s " "$u" "$(curl -s -o /dev/null -w "%{http_code}" "http://localhost:8000$u")"; done; echo'

# ⭐ شمارشِ خطاهای ۵۰۰ (بعد از هر تغییر باید صفرِ تازه باشد)
ssh carnameh 'grep -c "Internal Server Error" /var/log/carnameh-error.log'

# migration
ssh carnameh 'cd /opt/carnameh/app && /opt/carnameh/venv/bin/python manage.py migrate core'

# بکاپ
ssh carnameh '/usr/local/bin/carnameh-backup.sh'
```

⭐ **قبل از هر کاری:** ⭐ `md5sum` سه نسخه را بگیر و مطمئن شو یکی‌اند.
⭐ **بعد از هر کاری:** ⭐ آزمونِ سرتاسر (`/tmp/e2e.sh` روی سرور)، شمارشِ خطای ۵۰۰،
بعد به‌روزرسانیِ سند، بعد بکاپ.
