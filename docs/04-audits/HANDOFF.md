PGPASSFILE=/root/.pgpass psql -h localhost -U carnameh -d carnameh
```

⚠️ **برای ری‌استارت gunicorn از `pkill -f carnameh_backend` استفاده نکن** — الگو در خط فرمان
SSH خودت هست و پوسته را می‌کشد (خروجی ۶۵۲۸۰). درست:
```bash
kill -HUP $(pgrep -f "gunicorn carnameh_backend" | head -1)
```
