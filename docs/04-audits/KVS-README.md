## ۲) چهار قانون حاکم (در CHECK/NOT NULL اعمال شده‌اند، فقط سند نیست)

1. **مشخصه به تیپ می‌چسبد، نه به مدل** — `spec_value` کلید خارجی به `veh_variant` دارد
2. **`source_id` و `observed_at` اجباری‌اند** — تعمیم قاعدهٔ PR-01
3. **`null` = نامعلوم، `0` = صفر** — هرگز مخلوط
4. **پیشرانهٔ ناشناخته راه فرار ندارد** — `fuel_class` فقط ۱۰ مقدار مجاز دارد؛
   ناشناخته در `unclassified` می‌افتد و `v_unclassified_fuel` آن را نشان می‌دهد

## ۴) ⭐ نقطهٔ انحصاری: کد مدل ایرانی

از ۱٬۸۸۶ پرس‌وجوی واقعی:
```
«پژو 206 تیپ 2»   «پراید ۱۴۱ اسپرت»   «پراید ۱۱۱»   «پراید ۱۳۱ مدل ۹۰»
```
⚠️ «۱۱۱» و «۱۴۱» **سال نیستند — کد مدل‌اند**.
⇒ `veh_variant.model_plate` دقیقاً برای همین اضافه شد. هیچ استاندارد بین‌المللی
این را پوشش نمی‌دهد.

زبان محاوره‌ای هم پوشش داده شد: `veh_model.col_aliases`
(از پرس‌وجوها: `میزنه ۸۶` · `نمیشه ۸۲` · `نمیخوره ۷۳`)

## ۵) نام کامل ایرانی — تست‌شده

```
پژو ۲۰۶ تیپ ۲ TU5 بنزینی دستی
پژو ۲۰۶ E برقی اتوماتیک
```
دو قاعدهٔ ضدتکرار در ویو: اگر `trim_name` شماره دارد `model_plate` نمی‌آید؛
اگر `trim_name` واژهٔ سوخت دارد، `fuel_class` تکرار نمی‌شود.

## ۶) پشتوانهٔ استاندارد

| استاندارد | کاربرد |
|---|---|
| **UNECE WP.29** | `body_type` = M1/M2/M3/N1/N2/N3 |
| **ISO 3779:2009** | الگوی VIN (`veh_model.vin_pattern`) |
| **ISO 3833** | تعریف نوع خودرو |

**صادقانه:** ساختار دفترچه استاندارد مکتوب ندارد ⇒ «استانداد کارنامه» است، نه ISO.
