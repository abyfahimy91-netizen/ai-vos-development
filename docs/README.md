## 🧭 محصول در یک نگاه

> ⭐ **«دستیارِ مطمئنِ رانندهٔ ایرانی»** — کسی که می‌گوید خودرویت چه می‌کند،
> چرا، و چقدر خرج دارد.

| بُعد | وضعیت |
|---|---|
| جایگاه | ⭐ **مترجم و داور** — نه فروشگاه، نه بازارِ خدمات |
| زبان | فارسیِ محاوره‌ایِ محترمانه |
| واحدِ پول | ⭐ **ریال** (هر عدد باید منبع داشته باشد) |
| هویت | ⭐ **بدونِ لاگین** — ارزش پیش از ثبت‌نام |

⭐ **سه سفرِ کاربر** (قلبِ محصول):
1. 🆘 **اضطراری** — «توی راه پاره شد»
2. 🛠 **برنامه‌ریزی** — «می‌خوام برم تعمیرگاه»
3. 📅 **پیشگیرانه** — «یادم نمیاد روغن رو عوض کنم»

⭐ این‌ها سند نیستند؛ **قانونِ کارِ ما** هستند:

| قانون | خلاصه |
|---|---|
| ⭐ `L-05` | هر عدد منبع دارد یا صریحاً «نامعلوم» گفته می‌شود |

| ⭐ `G-47` | ⛔ جمع‌آوریِ موبایل ممنوع |
| ⭐ `G-53` | ⛔ قاعدهٔ ایمنی فقط از **دفترچهٔ رسمی** |

## 🔒 چه چیزی را عمداً نمی‌سازیم

⭐ این سندها فقط از «چه می‌سازیم» نمی‌گویند؛ از **چه نمی‌سازیم و چرا** هم می‌گویند:

| نمی‌سازیم | چرا |
|---|---|
| حساب کاربری و ورود | ⭐ ارزش باید پیش از ثبت‌نام باشد |
| رزرو و خدمات در محل | ⛔ خارج از دامنهٔ محصول |
| پیامک یادآوری | ⛔ `G-47` جمع‌آوریِ موبایل ممنوع |
| رتبه‌بندیِ تعمیرکار | ⛔ `G-23` تضادِ منافع |
| «تأییدِ تعمیرکار» | ⛔ به پروفایل و رکوردِ واقعی نیاز دارد |
