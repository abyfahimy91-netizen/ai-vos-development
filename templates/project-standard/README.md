# AI-VOS Project Standard Template

Version: 1.0

## Purpose

This template defines the standard starting structure for projects managed by AI-VOS.

It provides a common project memory and documentation foundation.

---

# Project Principle

Every project managed by AI-VOS must maintain its own repository.

This template is copied into the project repository during initialization.

---

# Structure

## Root Files

- PROJECT-IDENTITY.md
- CURRENT-PROJECT-STATE.md
- NEXT_PROJECT_TASK.md
- PROJECT-DECISIONS.md

---

- Business model documents.

## Tests

## Deployment

---

## History

Contains:

---

# Rule

This template is a starting point.

Each project may evolve independently without modifying AI-VOS core.
