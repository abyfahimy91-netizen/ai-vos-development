
# AI-VOS AI Reading Protocol

Version: 0.3

Status: Active


# Purpose

This document defines the official entry and reading process for any AI system entering the AI-VOS repository.

The purpose of this protocol is to ensure that any AI model can understand, analyze and continue AI-VOS development without access to previous chat history.

AI-VOS must be recoverable only from repository information.

The repository is the permanent memory of the system.


# Core Principle

Repository is the source of truth.

Chat history is temporary context only.

All permanent knowledge, decisions, system states and development instructions must exist inside repository documents.


# Important Separation Rule

Reading repository documents does not mean permission to modify the repository.

The AI must separate:

## Understanding Phase

The AI reads required documents and creates an understanding of the system.

## Design Phase

The AI analyzes possible solutions and prepares recommendations.

## Approval Phase

The human executor reviews and approves operational changes.

## Implementation Phase

Only after approval, operational actions may be performed.
