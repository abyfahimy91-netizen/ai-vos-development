# Product Design Engine - Inputs

## Required Inputs

| Input | Source | Description |
|-------|--------|-------------|
| Opportunity Report | Business Analysis Engine | Validated opportunity and market. |
| Revenue Model | Revenue Model Engine | Pricing tiers and revenue streams. |
| Product Vision | Human Operator | What the product should be. |

## Optional Inputs

| Input | Source | Description |
|-------|--------|-------------|
| Existing Docs | Project Repository | Any existing product specs. |
| User Research | Human / AI | Customer feedback data. |
| Brand Guidelines | Human Operator | Visual identity preferences. |
| Technical Constraints | Human / AI | Platform or skill limitations. |

## Rules

- Revenue Model must be approved before starting.
- Product vision from human operator is mandatory.
- If user research is missing, create assumptions and flag them.
