## Technology Stack

| Category | Selection | Reason |
|----------|-----------|--------|
| Hosting | GitHub Pages | Free, static, simple |
| Generator | Jekyll | GitHub default, no build needed |
| Styling | Custom CSS | Minimal, RTL control |
| Font | Vazirmatn | Free, popular, readable |
| Content | Markdown | Easy updates, version control |
| Version Control | Git | Standard, GitHub integration |

---

## Rejected Alternatives

### Static Site Generator
- Hugo: Requires separate install
- Eleventy: Smaller community
- No Generator: Hard to maintain

### CSS Framework
- Tailwind: Too complex for minimal
- Bootstrap: Heavy, not minimal

### Font
- IRANSans: License required
- Sahel: Less common

---

## Constraints Satisfied

- GitHub Pages compatible: Yes
- RTL support: Yes (Custom CSS)
- Minimal design: Yes
- Easy updates: Yes (Markdown)
- No server needed: Yes
