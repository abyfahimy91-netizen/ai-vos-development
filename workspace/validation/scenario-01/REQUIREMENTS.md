# Personal Website - Requirements Document

Version: 1.0
Date: 2026-07-28
Status: Approved

---

## Project Overview

A personal website for a developer to showcase portfolio,
blog posts, and contact information.

---

## Functional Requirements

| ID | Requirement | Priority | Status |
|----|-------------|----------|--------|
| F1 | Homepage with personal introduction | High | Required |
| F2 | Portfolio section (empty initially) | High | Required |
| F3 | Portfolio item detail pages | High | Required |
| F4 | Blog listing page | Medium | Required |
| F5 | Blog post content pages | Medium | Required |
| F6 | Contact page with info | Medium | Required |
| F7 | Contact form | Low | Optional |

---

## Non-Functional Requirements

| ID | Requirement | Priority |
|----|-------------|----------|
| NF1 | Fast page loading | High |
| NF2 | Responsive design for mobile | High |
| NF3 | Basic SEO support | Medium |
| NF4 | Basic security | Medium |
| NF5 | Easy content updates by owner | Medium |

---

## Constraints

| ID | Constraint |
|----|------------|
| C1 | Hosted on GitHub Pages |
| C2 | No custom domain initially |
| C3 | Content in Persian (Farsi) |
| C4 | Minimal design style |
| C5 | Owner updates content directly |
| C6 | No admin panel needed |
| C7 | No portfolio items initially |

---

## Answers to Questions

1. Hosting: GitHub Pages
2. Portfolio items: None initially
3. Content updates: Owner manages directly
4. Language: Persian (Farsi)
5. Design: Minimal
6. Domain: GitHub Pages default for now

---

## Out of Scope

- Admin panel
- User authentication
- Database
- Custom domain (initially)
- Contact form (optional, low priority)
